Accessibility Gaps
The app lacks proper ARIA labels, focus management for keyboard navigation, and sufficient color contrast in some areas. This excludes users with disabilities from fully using the service.
⚠️
Missing ARIA labels on interactive elements
Buttons and icons need aria-label attributes for screen readers
⚠️
No focus indicators for keyboard navigation
Add visible :focus styles to all interactive elements
⚠️
Insufficient color contrast in some areas
Muted text (#8a7863) on light backgrounds may fail WCAG AA
📏
Inconsistent Distance Formatting
Distance is displayed differently across the app — sometimes as "0.2 mi", other times as "0.2 miles", and occasionally without units. This creates confusion about whether distances are in miles or kilometers.
Current inconsistencies:
"0.2 mi" List view
"0.2 miles" Map pin labels
"0.3 km" Settings > Units (no toggle)
🧭
Navigation Flow Issues
The app lacks clear navigation patterns for returning to previous states. Users can get lost in detail views or filters without an obvious way back to their starting point.
✓ Recommended Improvements
  • → Add "Back to map" button in detail view header
  • → Show current filter state with clear/reset option
  • → Add breadcrumb or step indicator for multi-step flows
