UX Improvement: Error Resilience & Search Alternatives

Problem: When a user denies location permission, the app defaults to FALLBACK_CENTER (Seattle), but the UI doesn't clearly communicate that the user is no longer seeing "their" nearby places. This can cause confusion if they expect local results.

Solution: Implement a persistent "Location Unavailable" banner on the map. This banner should inform the user they are viewing Seattle and provide a clear action: "Search for another city" or "Retry Location Access".

Proposed Flow

  • Detection: If origin.is_none() and user is not in Seattle, show a top-mounted banner.
  • Contextual UI: The banner should say: "Showing places in Seattle. [Change Location]".
  • Actionable Error: Clicking "Change Location" opens the LocationPicker or a simple text search input to manually set the map center.
